# CSA09 Assignment 1 — Tasks 1 to 5

Campus Smart-Parking System — Java programs.

## Requirements
- Java JDK 8 or newer
- Compile and run each task separately from its folder.

## Folder structure
- `Task01/Task1.java` — basic object model: Vehicle and ParkingTicket
- `Task02/Task2.java` — data types and array representation
- `Task03/ParkingFacility.java` — allocate and release parking slots
- `Task04/Task4.java` — constructors, constructor chaining and copy constructor
- `Task05/Task5.java` — static ticket counter

## Compile and run
Open a terminal in the required task folder. For example:

```bash
cd Task03
javac ParkingFacility.java
java ParkingFacility
```

For other folders, use the matching `.java` filename and public class name.

## Notes
- Task 1 and Task 2 in the assignment also require written analysis, assumptions, data-type justification, and complexity discussion.
- Task 3 includes the completed code exercise from the assignment.
- Tasks 4 and 5 provide simple runnable examples of the required OOP concepts.
- Review and understand the code, and add your own test screenshots and written answers before submitting.
